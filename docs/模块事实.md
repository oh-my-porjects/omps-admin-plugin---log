# 操作审计 模块事实

## 职责

审计日志公共模块，负责写入和分页查询后台操作审计记录。

## 数据表

- `log_audit`

## API

- `GET /api/log/hello`：模块探活
- `POST /api/log/audit`：写入审计日志
- `GET /api/log/list`：查询审计日志
- `POST /api/log/admin/ping`：后台连通性检查

## 实时事件

用户前端事件：

- 当前模块没有自有用户前端推送事件。

后台提醒事件：

- 当前模块没有自有后台实时提醒事件。

## 测试资产

- `tests/data.yaml` 声明本模块测试涉及的数据表、种子、清理和快照范围。
- 每个 `api-docs/endpoints/*.json` 里的 `endpoint_key` 都应有对应 `tests/*.test.json`。
- 新增、删除或修改接口时，必须同时更新 `api-docs/`、测试文件和必要的数据种子。
